# UI 视觉刷新（2026-10-20）

保持原有卡片/浅色/蓝色强调风格，只做现代化收敛。

## 全局

- 背景：柔和渐变 `xy_bg_screen`（日间 #FAFBFE→#F1F3F8，夜间 #09090C→#0D0D12）。
- 卡片：圆角 20dp，0.8dp 低对比描边，白色/深灰卡片。
- 强调色：日间 #3478F6，夜间 #5B8CFF；辅助浅蓝 `xy_accent_soft`。
- 文本：标题 #111318 / #F5F5F7，次级 #6B7280 / #9CA3AF，分组标签 #8A8F98。
- 行高：设置行最小 60dp，内边距 16dp；标题 15sp，副标题 12sp，行距 1.28。
- 分组：上间距 24dp，小标题 12.5sp，英文标签 9sp + 0.12 letterSpacing。

## 组件

- 图标容器圆角 7dp→10dp；版本徽章改为胶囊；代码输入框 16dp 圆角。
- 预设芯片改为浅蓝底 + 强调色文字。
- 弹窗：`ThemeOverlay.Xiyu.Dialog`，28dp 圆角、同色 surface、蓝色按钮；
  `XyDialogTitle` / `XyDialogBody` 统一标题与正文。
